# Security

## Reporting a vulnerability

Please report a vulnerability in one of these SDKs privately, through GitHub's private vulnerability reporting for this repository (the **Security** tab, then **Report a vulnerability**). Please do not open a public issue or pull request for it.

Include the SDK and its version or commit, what you did, what you expected and what happened. Do not include a real API key, customer data or any credential. If you found a key in code or in a log, tell us that it exists, not what it is.

## What this covers

The code in this repository: the eight SDKs and their examples. It does not cover the Vunly API or website.

## What to expect

We read reports and fix what we confirm. We give no response time and no guarantee. There is no bounty program.

## For users of the SDKs

Keep your API key out of source code, tests, logs and prompts; read it from the environment. Each SDK's README lists its known limitations, including any that concern logging.
